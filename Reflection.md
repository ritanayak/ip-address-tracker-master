During the development of the IP Address Tracker, I focused on integrating a third-party API, building a dynamic user interface, and ensuring responsiveness across devices. My primary goal was to create a functional, visually appealing application that displays IP and domain information on an interactive map using Leaflet.

The development process began with structuring the HTML semantically and designing the CSS to provide a clean, responsive layout. I then implemented JavaScript to fetch data from the IPify API, dynamically updating the UI with the user’s IP, location, timezone, and ISP. Using async/await allowed for readable asynchronous operations, and I implemented error handling to manage failed network requests or incomplete API responses.

One of the main challenges was handling invalid user inputs, such as malformed IP addresses or domains, which could lead to API errors. I addressed this by implementing both IP and domain validation, ensuring that only proper inputs triggered API calls. Another challenge was formatting the timezone information consistently, which I solved by creating a utility function to display UTC offsets clearly. Additionally, ensuring the Leaflet map updated correctly with each search required careful management of markers and map view state.

For potential improvements, I could implement a more user-friendly error display instead of using alerts, include domain name auto-completion, or add more detailed geolocation data. Integrating environment-based API key management through a secret.js generation script ensures security, particularly for deployments. Overall, this project enhanced my understanding of API integration, asynchronous programming, error handling, and responsive UI design, resulting in a fully functional and visually appealing portfolio piece.
